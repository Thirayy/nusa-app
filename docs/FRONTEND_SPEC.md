# Frontend Specification — NUSA MVP

## Design System
- **Warm Cream** (Latar halaman): `#FAF7F0`[cite: 12]
- **Soft White** (Kartu & formulir): `#FFFFFF`[cite: 12]
- **Natural Teal** (Tombol utama & sukses): `#28665A`[cite: 12]
- **Terracotta** (Aksen & ilustrasi): `#D98652`[cite: 12]

## Standar Komponen & Navigasi
- Pemisahan navigasi secara tegas antara **Employer** dan **Worker**[cite: 12].
- Menggunakan API client terpusat dengan penanganan kredensial cookie `credentials: "include"`[cite: 13].
- Bahasa Indonesia yang mudah dipahami dan ramah pengguna awam.
